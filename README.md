## Описание программы (кратко)
**Movie Library** — это графическое приложение (GUI) для ведения персонального списка фильмов. Оно позволяет удобно структурировать информацию о кинокартинах, исключая потерю данных благодаря использованию формата JSON.

### Возможности (что программа умеет делать)
*   **Учет фильмов:** добавление названия, жанра, года и личного рейтинга.
*   **Валидация данных:** встроенная проверка на корректность (защита от ввода текста вместо года или некорректного рейтинга).
*   **Динамическая фильтрация:** поиск по коллекции по жанру или году выпуска в режиме реального времени.
*   **Локальное хранение:** автоматическое чтение и запись данных в файл `movies.json`.
*   **Удобное отображение:** вывод всего списка в виде интерактивной таблицы.

## Инструкция по запуску

### Требования для запуска программы
*   Операционная система: Windows, macOS или Linux.
*   Интерпретатор **Python** версии 3.10 или выше.
*   Библиотека **Tkinter** (обычно поставляется в комплекте с Python).

### Запуск (инструкция по запуску)
1.  Убедитесь, что у вас установлен Python (проверить в терминале: `python --version`).
2.  Скачайте файл с исходным кодом проекта (`main.py`).
3.  Откройте терминал (командную строку) в папке с файлом.
4.  Запустите программу командой:
    ```bash
    python main.py
    ```

### Примеры использования программы
*   **Сценарий 1 (Добавление):** Заполните поля (Название: *Интерстеллар*, Жанр: *Научная фантастика*, Год: *2014*, Рейтинг: *10*) и нажмите кнопку «Добавить фильм». Запись появится в таблице.
*   **Сценарий 2 (Фильтрация):** Введите в поле фильтра по жанру слово «Комедия». В таблице останутся только те фильмы, жанр которых соответствует запросу.
*   **Сценарий 3 (Проверка):** Если ввести в поле рейтинга число «12» или текст, программа выдаст предупреждающее окно об ошибке и попросит исправить значение на диапазон от 0 до 10.
